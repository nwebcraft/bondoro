# Capability: ユーザー管理

LINE友だち登録、ユーザー設定管理、コマンド処理を担当する。

## ADDED Requirements

### Requirement: LINE友だち追加時の自動登録

システムは、LINE公式アカウントに友だち追加されたユーザーを自動的に登録しなければならない（SHALL）。

#### Scenario: 新規ユーザーの友だち追加

- **WHEN** ユーザーがLINE公式アカウントを友だち追加する
- **THEN** ユーザー情報がDynamoDBに登録される
- **AND** デフォルト設定が適用される
- **AND** ウェルカムメッセージが送信される

#### Scenario: ブロック解除による再登録

- **WHEN** 過去にブロックしたユーザーがブロック解除する
- **THEN** 既存のユーザー情報が有効化される
- **AND** `notification_enabled` が `true` に更新される

### Requirement: デフォルト設定

新規登録ユーザーには、以下のデフォルト設定が適用されなければならない（SHALL）。

- `notification_enabled`: `true`
- `keywords`: `["ボンボンドロップ", "BONBON DROP"]`
- `sources`: `["rakuten", "yahoo", "ameblo"]`

#### Scenario: デフォルト設定の適用

- **WHEN** 新規ユーザーが登録される
- **THEN** 上記のデフォルト設定が適用される

### Requirement: LINEコマンドによる設定変更

システムは、ユーザーからのLINEメッセージを解析し、コマンドに応じた設定変更を行わなければならない（SHALL）。

対応コマンド:
- `設定`: 現在の設定を表示
- `通知ON` / `通知OFF`: 通知の有効/無効切替
- `キーワード追加 <word>`: 監視キーワード追加
- `キーワード削除 <word>`: 監視キーワード削除
- `ヘルプ`: 使い方を表示

#### Scenario: 設定コマンド

- **WHEN** ユーザーが「設定」と送信する
- **THEN** 現在の設定内容がメッセージで返信される
- **AND** 通知ON/OFF状態、登録キーワード、監視ソースが表示される

#### Scenario: 通知OFFコマンド

- **WHEN** ユーザーが「通知OFF」と送信する
- **THEN** `notification_enabled` が `false` に更新される
- **AND** 「通知をOFFにしました」と返信される

#### Scenario: 通知ONコマンド

- **WHEN** ユーザーが「通知ON」と送信する
- **THEN** `notification_enabled` が `true` に更新される
- **AND** 「通知をONにしました」と返信される

#### Scenario: キーワード追加コマンド

- **WHEN** ユーザーが「キーワード追加 グミシール」と送信する
- **THEN** `keywords` 配列に「グミシール」が追加される
- **AND** 「キーワード「グミシール」を追加しました」と返信される

#### Scenario: キーワード削除コマンド

- **WHEN** ユーザーが「キーワード削除 グミシール」と送信する
- **AND** 「グミシール」が `keywords` に存在する
- **THEN** `keywords` 配列から「グミシール」が削除される
- **AND** 「キーワード「グミシール」を削除しました」と返信される

#### Scenario: ヘルプコマンド

- **WHEN** ユーザーが「ヘルプ」と送信する
- **THEN** 使用可能なコマンド一覧と説明が返信される

#### Scenario: 不明なコマンド

- **WHEN** ユーザーが認識できないメッセージを送信する
- **THEN** 「コマンドが認識できませんでした。「ヘルプ」と送信してください」と返信される

### Requirement: ウェルカムメッセージ

システムは、友だち追加時にウェルカムメッセージを送信しなければならない（SHALL）。

メッセージ内容:
- サービスの説明
- 使い方の簡単な説明
- ヘルプコマンドの案内

#### Scenario: ウェルカムメッセージの送信

- **WHEN** 新規ユーザーが友だち追加する
- **THEN** ウェルカムメッセージが送信される
- **AND** メッセージには「ヘルプ」コマンドの案内が含まれる

### Requirement: LINE Webhook署名検証

システムは、LINE Webhookリクエストの署名を検証し、不正なリクエストを拒否しなければならない（SHALL）。

#### Scenario: 正当なWebhookリクエスト

- **WHEN** LINE Platformから正当な署名付きリクエストが送信される
- **THEN** リクエストが処理される

#### Scenario: 不正な署名のリクエスト

- **WHEN** 不正な署名のリクエストが送信される
- **THEN** HTTP 401エラーを返す
- **AND** 警告ログを記録する
